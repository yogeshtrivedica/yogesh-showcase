# yogesh-showcase

Personal site for CA Yogesh Trivedi. Static React site, hosted on Vercel.

- All page text lives in `frontend/src/data/profile.js`.
- Booking-form enquiries are emailed to the address in `profile.email` via formsubmit.co.
- Vercel settings: Root Directory = `frontend` (build config is in `frontend/vercel.json`).
